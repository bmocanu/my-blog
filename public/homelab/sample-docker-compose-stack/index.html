Sample: Self-Hosted Services with Docker Compose
Posted on 2026-08-18 :: docker homelab sample

docker-compose.yml

services:
  jellyfin:
    image: jellyfin/jellyfin
    ports:
      - "8096:8096"
    volumes:
      - ./config:/config
      - /mnt/media:/media:ro
    restart: unless-stopped

Updating

docker compose pull && docker compose up -d
