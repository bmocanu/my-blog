Before buying anything, I set up the basics: a network layout, a place for the equipment and a list of the services I want to run.

## The network layout

A single switch, one subnet for the servers and one for the rest of the devices. Nothing fancy at this point.

## The service list

- A hypervisor to host the virtual machines.
- A container host for the small services.
- A backup target.
